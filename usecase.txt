Aktor yang TerlibatActor (Pengguna): Berada di sisi paling kiri, bertindak sebagai pemicu utama yang ingin mengakses atau berinteraksi dengan sistem keamanan akun (proses login dan pemulihan akun).   2. Kelompok Fitur (Use Case) UtamaDi dalam kotak batas sistem (Diagram Heading), terdapat dua jalur utama fungsionalitas:   A. Jalur Fungsionalitas "Lupa Kata Sandi" (Forgot Password Flow - Sisi Kiri)Jika kita menganggap bentuk-bentuk oval di bawah sebagai Use Case yang saling terhubung berurutan:Lupa Kata Sandi: Use Case awal ketika pengguna mengeklik opsi pemulihan akun.   Minta Reset Kata Sandi & Verifikasi Email: Sistem memproses permintaan dan mengecek validitas email.   Jika Berhasil, sistem melanjutkan ke Use Case Kirim Tautan Reset $\rightarrow$ Buka Tautan Reset $\rightarrow$ Masukkan Kata Sandi Baru.   Sistem lalu memeriksa kecocokan sandi (decision "Kata Sandi Cocok?"). Jika cocok, dijalankan Use Case Perbarui Kata Sandi dan menampilkan konfirmasi berhasil. Jika tidak cocok, sistem memunculkan pesan ketidaksesuaian.   Jika Gagal pada tahap verifikasi email, sistem menjalankan Use Case Tampilkan Pesan Kesalahan.   B. Jalur Fungsionalitas "Login & Manajemen Sesi" (Authentication & Session Flow - Sisi Kanan)Ini adalah inti dari fungsionalitas utama sistem:Login & Masukkan Kredensial: Pengguna memasukkan data masuk untuk divalidasi oleh sistem (Validasi Kredensial).   Skenario Valid (Berhasil):Sistem menjalankan Use Case Autentikasi Pengguna dan memeriksa status akun (Akun Aktif?).   Jika Ya (Aktif): Sistem berurutan mengeksekusi Use Case Buat Sesi Pengguna $\rightarrow$ Akses Dashboard $\rightarrow$ pengguna berinteraksi hingga memilih Logout $\rightarrow$ Hapus Sesi Pengguna $\rightarrow$ Selesai.   Jika Tidak (Tidak Aktif): Sistem menjalankan Use Case Tampilkan Akun Tidak Aktif lalu langsung Selesai.   Skenario Tidak Valid (Gagal):Sistem menjalankan Use Case Tampilkan Pesan Kesalahan.   Sistem memberikan opsi (decision "Coba Lagi?"): jika memilih Ya, dikembalikan ke form login; jika Tidak, proses berakhir di Use Case Selesai.
